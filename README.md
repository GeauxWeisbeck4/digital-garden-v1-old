# WeisGarden

The digital garden of Andrew Weisbeck, built with Astro, TailwindCSS, Alpine.js, React.js, and other Astro integrations. It is a place where ideas are introduced, developing, connected, and solutions are produced through creative techniques, feedback, and collaborative efforts.

Currently, you will find a journal, basic garden section with seedling/blossiming/evergreen notes, "blog posts" or published articles, an About Me section, and last but definitely not least, the support page where you can find out how to help Andrew create awesome stuff!

## Objectives

- Don't take self too seriously - allow for creative play and critical thinking to solve problems that aren't getting solved by trying the serious problem solving tactics.
- Share my thoughts, beliefs, knowledge, and vision for healing the world. I have had some very difficult times, unique experiences, and been a part of some of the most beautiful interactions in my life - these are all worth sharing in a way that is useful for others.
- Teach what I know to you. Learn from you what I don't know. Build things together. Destroy evil together... I don't know, I need a friend y'know? jk jk but I'm all about community and am going to be sharing the WeisMind Community in due time.
- Create content from ideas that get properly absorbed into a space where connections can generate new and creative ideas and projects.
- Support my creative activities, especially since I'm just back into being housed and looking for work - it's hard surviving right now and any help is so amazing.

## What is the workflow at play here?

There are so many different ways to explore this space and the topics involved, so I try to keep it fresh and try new things and improve the creative and critical thinking methods that already work. The current work flow starts with the daily journal, branches into notes, and then over time, new content collections and objects will be created to match the object state that my ideas morph into over time.

### Getting Started

1. Clone the repository to your machine
2. Navigate into the directory
3. Install the dependencies
4. Serve up the site and BOOM! WEISGARDEN!
5. Code and resolve issues to my absolute delight.

```bash
git clone https://github.com/geauxweisbeck4/digital-garden-astro.git
cd digital-garden-astro
npm install
npm run dev
```
